# 系统集成 (SYS.4)

## 概述

本集成规划自 `docs/system-architecture.md` 的 2 个系统元素确定性派生，按元素顺序生成集成步骤，每步标注集成对象与接口验证点。

## 集成策略

- 集成顺序按系统元素依赖关系自底向上，先集成无依赖元素。
- 桩/驱动按接口规范构造。
- 集成序列在 `.osh/ci/` 中复现（软件层集成测试 SWE.5 提供执行记录）。

## 集成序列

| 集成步骤 | 系统元素 | 覆盖需求 | 集成内容与验证点 |
|:---------|:---------|:---------|:----------------|
| INT-001 | SE-01 | SYS-REQ-001 | 集成 SE-01（承载「yuleOSH 项目规范 — E2E Test Project」能力；对外…）；验证接口数据流正确性 |
| INT-002 | SE-02 | SYS-REQ-002 | 集成 SE-02（承载「系统需求追溯」能力；对外仅通过已定义接口交互，不越界承担其他元素职责）；验证接口数据流正确性 |

## 集成覆盖矩阵

## 可追溯性

- 集成步骤覆盖 `docs/system-architecture.md` 中的 2 个系统元素。
- 集成项 → 系统架构元素（SYS.2）映射见本文「集成覆盖矩阵」章节。
- 系统集成结果向上追溯至系统需求（SYS.1），向下关联软件组件（SWE.3）。

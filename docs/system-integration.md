# 系统集成 (SYS.4)

## 概述

本集成规划自 `docs/system-architecture.md` 的 20 个系统元素确定性派生，按元素顺序生成集成步骤，每步标注集成对象与接口验证点。

## 集成策略

- 集成顺序按系统元素依赖关系自底向上，先集成无依赖元素。
- 桩/驱动按接口规范构造。
- 集成序列在 `.osh/ci/` 中复现（软件层集成测试 SWE.5 提供执行记录）。

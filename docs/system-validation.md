# 系统确认 (SYS.5)

## 概述

本确认规划自系统需求（SYS-REQ-xxx）—— **降级**：无涉众需求文件，确认针对系统需求而非涉众需求（V 模型方向倒置）确定性派生，共 20 条需求对应 20 个确认场景。

> 派生来源 (机读): `spec-derived`

## 确认策略

- 在目标或等效环境下运行用户场景，确认满足涉众需求。
- 确认场景复用软件合格性测试（SWE.6）的仿真/HIL 证据。
- 每条涉众需求具备可执行验收准则与通过判据。

# 系统确认 (SYS.5)

## 概述

本确认规划自系统需求（SYS-REQ-xxx）—— **降级**：无涉众需求文件，确认针对系统需求而非涉众需求（V 模型方向倒置）确定性派生，共 2 条需求对应 2 个确认场景。

> 派生来源 (机读): `spec-derived`

## 确认策略

- 在目标或等效环境下运行用户场景，确认满足涉众需求。
- 确认场景复用软件合格性测试（SWE.6）的仿真/HIL 证据。
- 每条涉众需求具备可执行验收准则与通过判据。

| 确认场景 | 覆盖需求 | 确认内容与验收准则框架 |
|:---------|:---------|:----------------------|
| VAL-001 | SYS-REQ-001 | 在目标/等效环境下运行用户场景，确认满足「yuleOSH 项目规范 — E2E Test Project」；验收准则待确认计划细化 |
| VAL-002 | SYS-REQ-002 | 在目标/等效环境下运行用户场景，确认满足「系统需求追溯」；验收准则待确认计划细化 |

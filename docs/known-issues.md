# 已知问题跟踪 (SUP.9)

## 问题管理流程

1. **识别**: 任何人发现缺陷均可提交，分配唯一 ID (ISSUE-xxx)
2. **分析**: 48 小时内完成严重度评估与根因分析
3. **解决**: 按严重度排定修复优先级
4. **验证**: 修复后经 QA 验证确认闭环
5. **关闭**: 验证通过后更新状态为「已关闭」

## 严重度定义

| 等级 | 名称 | 定义 | 修复 SLA |
|------|------|------|----------|
| S1 | 致命 | 系统崩溃/数据丢失/安全漏洞 | 24 小时 |
| S2 | 严重 | 核心功能不可用，无 workaround | 3 工作日 |
| S3 | 一般 | 功能异常但有 workaround | 7 工作日 |
| S4 | 轻微 | UI/文档/非功能性问题 | 下一里程碑 |

# 角色约束 — Verifier（Codex）

以下专家画像与命令参考来自 automotive-claude-code-agents，由 yuleOSH 按角色聚合。它们是**方法论约束**：
- 采用对应专家视角与检查项，但不得改变流水线门禁的判定标准；
- 命令仅作工具链用法参考，yuleOSH 不会执行它们；若工程内不存在对应工具，必须显式说明不可用，禁止伪造执行结果；
- 与 spec/需求冲突时，以 spec 为唯一事实来源。
